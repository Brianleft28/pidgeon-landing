# Reglas de Pidgeon Solutions

- **Objetivo Principal:** Mantener la aplicación lo más simple posible, funcionando exclusivamente como una *landing page* estática/informativa.
- **Sin Funcionalidades Complejas:** 
  - Está estrictamente PROHIBIDO implementar o mantener métodos de pago (Mercado Pago, Stripe, etc.).
  - Está estrictamente PROHIBIDO implementar o mantener sistemas de inicio de sesión (Login, Auth).
- **Consistencia UI/UX:**
  - Tecnología estricta: **Svelte 5** y **Tailwind CSS v4**.
  - Prohibido usar estilos distintos a los que ya existen.
  - Al crear o modificar componentes, se debe imitar con la máxima precisión la tecnología, el diseño y las clases de Tailwind que ya utiliza la UI actual. No introduzcas nuevas paletas de colores ni componentes externos.
